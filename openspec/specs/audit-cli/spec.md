# audit-cli Specification

## Purpose
Контракт командной строки: как утилита принимает пути на вход, какими флагами управляется и какими
кодами возврата отчитывается — чтобы её можно было и запускать руками, и встраивать в сборку.

## Requirements

### Requirement: Целевая платформа утилиты
Утилита ДОЛЖНА собираться под `net6.0` и НЕ ДОЛЖНА иметь ни одного `PackageReference`.
Собранный бинарь ДОЛЖЕН запускаться на машинах, где установлен только более новый рантайм.

#### Scenario: Сборка без доступа к NuGet
- **GIVEN** машина без доступа к внешним фидам, но с net6-таргетинг-паком
- **WHEN** выполняется сборка проекта
- **THEN** сборка проходит, поскольку восстанавливать нечего

#### Scenario: Запуск на машине с более новым рантаймом
- **GIVEN** машина, где установлен только рантайм .NET 8
- **WHEN** запускают собранную под net6 утилиту
- **THEN** она работает за счёт `RollForward=LatestMajor`

### Requirement: Разрешение входных путей
Утилита ДОЛЖНА принимать на вход `project.assets.json`, папку проекта, файл проекта
(`.csproj`/`.fsproj`/`.vbproj`), файл решения или папку решения, и ДОЛЖНА поддерживать
рекурсивный поиск всех assets-файлов.

#### Scenario: Путь к папке проекта
- **GIVEN** путь к папке, в которой есть `obj/project.assets.json`
- **WHEN** утилита разрешает вход
- **THEN** берётся этот assets-файл

#### Scenario: Путь к csproj без выполненного restore
- **GIVEN** путь к `.csproj`, рядом с которым нет `obj/project.assets.json`
- **WHEN** утилита разрешает вход
- **THEN** выводится сообщение о необходимости выполнить `dotnet restore`

#### Scenario: Решение целиком
- **GIVEN** путь к папке решения и флаг рекурсивного поиска
- **WHEN** утилита разрешает вход
- **THEN** находятся все `**/obj/project.assets.json`, а служебные папки вроде `bin` и `node_modules`
  пропускаются

#### Scenario: Несколько проектов в одном отчёте
- **GIVEN** несколько найденных assets-файлов
- **WHEN** утилита формирует отчёт
- **THEN** каждый проект представлен своим разделом со своими таргетами

### Requirement: Коды возврата
Утилита ДОЛЖНА возвращать 0 при успехе, 1 при ошибке выполнения и 2 при наличии находок уровня,
заданного порогом отказа. По умолчанию порог отказа НЕ ДОЛЖЕН быть установлен.

#### Scenario: Находки есть, порог не задан
- **GIVEN** запуск без порога отказа на проекте с ошибками
- **WHEN** утилита завершается
- **THEN** код возврата 0

#### Scenario: Порог отказа сработал
- **GIVEN** запуск с порогом отказа «ошибка» на проекте, где есть ошибки
- **WHEN** утилита завершается
- **THEN** код возврата 2

#### Scenario: Вход не найден
- **GIVEN** путь, которого не существует
- **WHEN** утилита завершается
- **THEN** код возврата 1, а причина выведена в поток ошибок

### Requirement: Справка на русском языке
Утилита ДОЛЖНА выводить справку с описанием всех параметров, кодов возврата и примерами запуска
при запросе справки и при запуске без аргументов.

#### Scenario: Запуск без аргументов
- **GIVEN** запуск без параметров
- **WHEN** утилита завершается
- **THEN** печатается справка, а код возврата 1

#### Scenario: Неизвестный параметр
- **GIVEN** запуск с несуществующим флагом
- **WHEN** утилита разбирает аргументы
- **THEN** печатается сообщение с указанием этого флага и подсказка про `--help`, код возврата 1

### Requirement: Выбор форматов и каталога вывода
Утилита ДОЛЖНА позволять запрашивать каждый формат отчёта по отдельности или все сразу, задавать
имя файла для каждого формата и общий каталог вывода.

#### Scenario: Формат без имени файла
- **GIVEN** флаг формата без значения
- **WHEN** утилита записывает отчёт
- **THEN** используется имя по умолчанию в каталоге вывода, а путь записанного файла печатается

#### Scenario: Каталог вывода не существует
- **GIVEN** указанный каталог вывода отсутствует
- **WHEN** утилита записывает отчёты
- **THEN** каталог создаётся

### Requirement: Взаимоисключающие и зависимые параметры
Утилита ДОЛЖНА отклонять параметры, применённые вне подходящего режима, до начала анализа.

#### Scenario: Точный режим без онлайн-режима
- **GIVEN** запуск с точным режимом чтения пакетов, но без флага онлайн-режима
- **WHEN** утилита разбирает аргументы
- **THEN** выводится сообщение, что параметр имеет смысл только вместе с онлайн-режимом,
  код возврата 1
